# Tuning Guide

## Basic Tuning Workflow

1. Enable engineering mode
2. Leave room empty
3. Observe noisy gates
4. Reduce max detection gates
5. Increase noisy thresholds
6. Test with real occupancy
7. Disable engineering mode

## Recommended Starting Settings

| Setting | Suggested |
|---|---|
| Timeout | 5-15 seconds |
| Max Moving Gate | 4-6 |
| Max Still Gate | 4-6 |
